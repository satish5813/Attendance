# Sample Collection Flutter App

This Flutter project is a minimal starting point for managing sample collection orders. It allows a manager to assign collection tasks to agents and uses a placeholder for map routing.

## Features

- List of sample collection orders
- Assign orders to agents
- Placeholder for displaying the customer's location on a map

## Getting Started

1. Ensure you have Flutter installed.
2. Run `flutter pub get` in this directory.
3. Launch the app with `flutter run`.

This project uses the `provider` package for simple state management and references `google_maps_flutter` for map functionality.
